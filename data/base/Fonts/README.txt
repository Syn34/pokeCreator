DEFAULT FONTS
=============

Fonts in this folder are the default for every project. A project keeps using
the default even if you add fonts to its Fonts folder, until you tick
"Use my own font" in Game Settings and pick one as the Message font.

PokeCreator's default message font is "power green.ttf", the FireRed /
LeafGreen style font that comes with Pokemon Essentials (Essentials\Fonts).
Copy power green.ttf (and power green small.ttf / power green narrow.ttf if
you like) into this folder.

Build Game copies the default fonts into the game when it uses them.
