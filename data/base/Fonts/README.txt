DEFAULT FONTS
=============

Fonts in this folder are used by every project that has no fonts of its own
in its Fonts folder. Once you add a .ttf to a project's Fonts folder, that
project uses its own fonts instead.

PokeCreator's default message font is "power green.ttf", the FireRed /
LeafGreen style font that comes with Pokemon Essentials (Essentials\Fonts).
Copy power green.ttf (and power green small.ttf / power green narrow.ttf if
you like) into this folder.

Build Game copies these fonts into the game when the project has none.
